How it works

Running in about ten minutes

One Docker Compose stack with the web app, API, database, queue worker and scheduler. Follow along, no experience with servers needed.

Read the full guide
01

Get a small server

Any Linux machine with Docker. A VPS with 2 GB of RAM is plenty for a household.

# install Docker
curl -fsSL \
  https://get.docker.com \
  | sudo sh
02

Download and configure

Clone the repository and fill in two short settings files.

git clone …/ledgerfly.git
cd ledgerfly
cp .env.example .env
03

Start everything

One command starts the whole stack. Add Caddy in front for HTTPS.

docker compose up -d
# migrations run on start
04

Create your account

The first sign up becomes the admin. Set up email, sign-ups and alerts from Settings.

FAQ

Questions, answered

Is LedgerFly free?

Yes. LedgerFly is open source under the AGPL-3.0 license. There is no paid tier and no account with us; you run it on your own server.

Where is my financial data stored?

Only in the database on your server. LedgerFly has no tracking or telemetry, and it only contacts outside services you turn on, such as exchange rates, email or ntfy.

What kind of server do I need?

Any Linux machine that runs Docker. A small VPS with 2 GB of RAM is plenty for a household, and a home server works too.

Can I share a ledger with my family?

Yes. Invite people to a ledger as an owner, editor or viewer. Everyone signs in with their own account.

Can I import my bank statements?

Yes. Import CSV files with column mapping and saved profiles, or camt.053 statements. Duplicates are detected and your rules run on imported transactions.

Is there a mobile app?

Yes. The Android app is coming to Google Play, and the iOS app can be built from source with Xcode. The web app also works on phones. See the apps page.
